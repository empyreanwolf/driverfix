# WifiFix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-button Windows 10 tool, run from a USB stick, that finds the missing built-in WiFi driver and installs it (offline pack first, online fallback via a temporary USB adapter, saving downloads back to the pack).

**Architecture:** `WifiFix.Core` (netstandard2.0, all logic behind interfaces, unit-tested on Linux with fakes) + `WifiFix.App` (net48 WinForms, ships as one small exe because .NET Framework 4.8 is built into Windows 10) + `PackBuilder` (console, builds `index.json` from driver folders). Windows-only parts (WMI, pnputil, Windows Update API) are thin adapters tested manually on a real PC.

**Tech Stack:** C#, netstandard2.0 / net48, xUnit (net8 test project), WMI (System.Management), `pnputil`, Windows Update Agent COM API.

**Spec:** `docs/design.md`

## Global Constraints

- Target Windows 10 64-bit; no runtime installs (net48 only, no .NET 8 on target).
- Must work with zero internet (offline path).
- One button, no prompts; manifest `requireAdministrator`.
- Pack layout: `drivers/win10/<vendor>/<chip>/*.inf` plus `drivers/index.json`. OS folder is a parameter so `win11` can be added later.
- Chips covered by pack: Intel AC 7265/8260/8265/9260/9560, AX200/201/210/211; Realtek; Qualcomm/Atheros; MediaTek; Broadcom; plus USB adapter chipsets Realtek RTL81xx/88xx, MediaTek MT76xx, Ralink.
- Logs to `logs/` on the stick (PC model, chip ID, result). Never fail a run because logging or save-back failed.
- No auto-run on USB insert (Windows 10 blocks it); launcher is one double-click.

## Review Focus

- PC with no WiFi hardware at all (wired desktop): say "No WiFi hardware found", change nothing.
- WiFi already working: say "WiFi already working", change nothing.
- Two missing devices (WiFi + Bluetooth combo, or WiFi + adapter): only WiFi devices get touched; each handled independently.
- Unsigned/wrong-arch INF makes `pnputil` fail: report failure and continue to the online fallback, never leave a half-state.
- USB stick read-only or path with spaces/non-ASCII: install still works; save-back failure is only a log warning.

## File Structure

- `src/WifiFix.Core/InfParser.cs` — hardware IDs from an INF.
- `src/WifiFix.Core/PackIndex.cs` — build/load/match index.
- `src/WifiFix.Core/DeviceInfo.cs`, `DeviceFilter.cs` — device model and "is a missing WiFi device" rule.
- `src/WifiFix.Core/PnpUtil.cs` — pnputil command building and result parsing.
- `src/WifiFix.Core/FixRunner.cs` — orchestration, logging.
- `src/WifiFix.Core/Interfaces.cs` — `IDeviceScanner`, `IProcessRunner`, `IOnlineProvider`, `IWifiVerifier`, `ILog`.
- `src/WifiFix.App/` — WinForms UI, Windows adapters (`WmiDeviceScanner`, `WuaOnlineProvider`, `WifiVerifier`, `ProcessRunner`), `app.manifest`.
- `src/PackBuilder/` — console tool.
- `tests/WifiFix.Core.Tests/` — xUnit.

### Task 5: FixRunner orchestration

**Files:**
- Create: `src/WifiFix.Core/FixRunner.cs`; add `IOnlineProvider`, `IWifiVerifier`, `ILog` to Interfaces.cs
- Test: `tests/WifiFix.Core.Tests/FixRunnerTests.cs`

**Interfaces:**
- Consumes: `IDeviceScanner`, `PackIndex`, `PnpUtil`, `DeviceFilter`.
- Produces: `interface IOnlineProvider { bool HasInternet(); string? Download(DeviceInfo d, string workFolder); /* returns folder with INF, or null */ }`; `interface IWifiVerifier { bool WifiAdapterUp(); bool AnyWifiAdapterPresent(); }`; `interface ILog { void Info(string m); void Warn(string m); }`; `enum RunOutcome { NoWifiHardware, AlreadyWorking, Fixed, FixedRebootNeeded, NotFixed }`; `class FixRunner { FixRunner(IDeviceScanner, IWifiVerifier, PackIndex, PnpUtil, IOnlineProvider, string packRoot, ILog); RunOutcome Run(); }`.
- Flow: scan → missing WiFi devices; none: `AnyWifiAdapterPresent()` ? AlreadyWorking : NoWifiHardware. For each device: pack match → install; else if `HasInternet()` → `Download` → install → copy to `drivers/win10/downloaded/<id>/`, `index.Add`, `Save` (failures only `Warn`). Finish: `WifiAdapterUp()` → Fixed/FixedRebootNeeded else NotFixed.

- [ ] **Step 1: Failing tests (all fakes):** `No_missing_devices_and_no_adapter_returns_NoWifiHardware_and_installs_nothing`; `No_missing_devices_and_adapter_present_returns_AlreadyWorking`; `Pack_match_installs_without_calling_online`; `No_pack_match_downloads_installs_and_saves_back_to_index`; `Install_failed_falls_through_to_online`; `Savedback_failure_does_not_fail_run`; `Two_missing_devices_each_handled_and_bluetooth_untouched`; `Reboot_needed_maps_to_FixedRebootNeeded`; `No_match_and_no_internet_returns_NotFixed`.
- [ ] **Step 2–4:** FAIL → implement → PASS. Commit `feat: fix orchestration`.
